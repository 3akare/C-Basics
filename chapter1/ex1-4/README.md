# Exercise 1-4

Modify the temperature conversion program to print a heading above the table.

## Solution
The solution demonstrates a temperature conversion (Celsius to Fahrenheit) program with a heading above the table.

## How to Run
```bash
gcc solution.c -o solution
./solution
```
